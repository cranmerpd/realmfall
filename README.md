# Realmfall

A free browser toy. Realms expand, fight, and break apart into new nations.

## Play it

After GitHub Pages is turned on, open:

https://cranmerpd.github.io/realmfall/

## Pages (one-time)

Repository **Settings → Pages → Build and deployment**:

- Source: **Deploy from a branch**
- Branch: **main** / **/ (root)**

Save, wait about a minute, then refresh the address above.
